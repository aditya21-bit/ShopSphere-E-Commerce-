# 🛍️ ShopSphere - E-Commerce Web Application

ShopSphere is a full-stack E-Commerce Web Application developed using the MERN Stack. It provides a seamless online shopping experience with secure user authentication, product management, shopping cart, order processing, and an admin dashboard.

---

## 📌 Project Objective

The objective of this project is to develop a modern e-commerce platform where users can browse products, add items to the cart, place orders, and manage their accounts while administrators can efficiently manage products and customer orders.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/shopsphere.git
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Backend

```bash
cd backend

npm install

npm run dev
```

# Environment Variables

## Backend (.env)
